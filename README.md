Die offizielle, ultra-schnelle und ressourcenschonende Web-Präsenz für den Twitch-Streamer **binchrii**. Entwickelt mit purem, sauberem HTML5, modernem CSS3 (Cyberpunk/Neon Gaming-Ästhetik) und schlankem Vanilla JavaScript — **100% Framework-frei, blitzschnell und ohne Overhead**.

👉 **Live-Website:** [https://benzjeremy.github.io/binchrii/](https://benzjeremy.github.io/binchrii/)

---

## ✨ Features

- ⚡ **Zero-Bloat Architektur:** Reines, valides semantisches HTML5 & CSS3 — keine Node-Module, kein Hydration-Overhead.
- 🟣 **Streamer Cyberpunk Aesthetic:** Modernes Dark-Theme (`#090a0f`) mit Neon-Akzenten (Twitch Violett `#9146ff` & Neon Cyan `#00f0ff`), Glaseffekten und Micro-Interactions.
- 🔴 **Live-Stream Integration:** Direkte Verlinkung zum Twitch-Kanal sowie interaktiver Inline-Player-Modus.
- 📅 **Sendeplan (Schedule):** Wöchentliche Streamzeiten und Event-Übersicht auf einen Blick.
- 💬 **Chat-Befehle Verzeichnis:** Übersicht über Chat-Commands (`!socials`, `!discord`, `!schedule`, `!rules`, etc.) mit 1-Klick-Kopierfunktion.
- 🛡️ **Community Guidelines:** Klare Verhaltensregeln für Stream, Chat und Discord.
- 📱 **100% Responsive:** Perfekt optimiert für Smartphones, Tablets und Widescreen-Monitore.
- ⚖️ **Rechtssicherheit:** DSGVO-konforme Datenschutzerklärung und vollständiges Impressum.

## 🛠️ Entwicklung & Struktur

```
binchrii/
├── index.html         <- Hauptseite mit Hero, Stream-Status, Schedule & Commands
├── impressum.html     <- Rechtliches Impressum (§ 5 TMG / DDG)
├── datenschutz.html   <- Datenschutzerklärung (DSGVO)
├── style.css          <- Cyberpunk/Neon Styles & responsive Layout
├── app.js             <- Interaktive UI-Features & Clipboard-Handler
├── favicon.svg        <- Neon Gamer Favicon
├── robots.txt         <- Suchmaschinen-Konfiguration
├── sitemap.xml        <- XML-Sitemap
├── .nojekyll          <- Direkte GitHub Pages Auslieferung
└── LICENSE            <- GNU General Public License v3.0
```
