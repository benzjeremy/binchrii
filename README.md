The official, ultra-fast, and resource-friendly web hub for Twitch streamer **binchrii**. Built with clean semantic HTML5, modern CSS3 (Cyberpunk/Neon gaming aesthetics), and lightweight vanilla JavaScript — **100% framework-free, lightning-fast, and zero bloat**.

👉 **Live Website:** [https://benzjeremy.github.io/binchrii/](https://benzjeremy.github.io/binchrii/)

---

## ✨ Features

- ⚡ **Zero-Bloat Architecture:** Pure semantic HTML5 & CSS3 without Node.js runtime or hydration overhead.
- 🟣 **Streamer Cyberpunk Aesthetic:** Modern dark theme (`#090a0f`) with neon accents (Twitch Violet `#9146ff` & Neon Cyan `#00f0ff`), frosted glass layers, and micro-interactions.
- 🔴 **Live Stream Integration:** Direct links to the Twitch channel alongside an interactive inline player toggle.
- 📅 **Stream Schedule:** Weekly streaming schedule and event overview at a glance.
- 💬 **Chat Command Directory:** Interactive list of chat commands (`!socials`, `!discord`, `!schedule`, `!rules`, etc.) with one-click clipboard copy.
- 🛡️ **Community Guidelines:** Clear community conduct guidelines for Twitch chat and Discord.
- 📱 **100% Responsive:** Optimized across mobile smartphones, tablets, and desktop displays.
- ⚖️ **Legal Compliance:** In-app / internal legal disclosure (§ 5 DDG) and GDPR privacy policy.
